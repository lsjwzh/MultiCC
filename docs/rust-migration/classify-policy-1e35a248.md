## 迁后复核

1. 分类词汇改接后剩余 384 个可达文件。每组闭包持有同一份目录，谓词严格校验字符串。展示值按普通 JS 属性读取；无需覆盖的结果按原引用返回。原 CommonJS 路径保留兼容导出。
2. API 错误策略改接后剩余 383 个可达文件。运行时通过绑定的宿主对象持有独立 Map 和可注入的 clock/random/logger/metrics；同一份策略内的投影持有同一个 policyPorts。保留先记录决策再写日志的异常边界和冻结的重复请求结果。
