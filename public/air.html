GETTING STARTED

开始之前，先完成两项配置

  1. 准备模型：在「CLI 与 Provider」里导入你已有的 API 线路，或直接使用 CLI 自带的登录。没有可用模型，任务无法执行。
  2. 配置 AI Assistant：它是 MultiCC 的核心——消息分类、任务归属、自动推进都依赖它，必须配置。选一个便宜的 flash / 轻量模型即可，不必占用主力模型。
未检测到任何 CLI：MultiCC 通过 CLI 执行任务与模型调用，请先至少安装一个并登录，否则模型与 AI Assistant 都无法工作。
