🌐 Chrome 隔离出口启动器

每个身份 = 一份完全隔离的 Chrome profile + 一个强制出口。出口可以是本机代理端口，也可以是 Clash 订阅里的节点（由插件自带的 meow 内核承接）；家宽/住宅代理常需要先经节点跳板，填在「上游」里就是 本机 → 跳板节点 → 住宅代理 → 目标站。固定代理不配置直连备用；出口不可用时网页请求失败。浏览器参数并非系统级断网保护。

新建 / 编辑身份

订阅里的 vmess/trojan 等协议由插件自带的 meow 内核运行；每个身份一个独立实例与端口。

无需手动安装。每身份固定配置，登录态保留；指纹模式先加载扩展再打开指定网址，不自动恢复上次全部标签。取消勾选则使用普通启动和 Chrome 原生标签恢复。
